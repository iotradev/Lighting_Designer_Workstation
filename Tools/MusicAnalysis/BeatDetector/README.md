# 节拍检测工具 (BeatDetector)

音频WAV文件节拍检测与分析工具，专为灯光设计工作站打造。

## 功能特性

### 核心功能
- **WAV音频加载** - 支持8/16/32位WAV文件
- **节拍检测** - 基于频谱通量(Spectral Flux)的起始检测算法
- **强弱拍识别** - 自动区分强拍(Downbeat)与弱拍(Weak Beat)
- **小节划分** - 智能将节拍分组为3拍或4拍小节
- **BPM估计** - 基于节拍间隔中位数的稳健BPM计算

### 导出格式
- **CSV** - beat_number, timestamp, strength, bar_number
- **MA时间码** - HH:MM:SS:FF格式，适配MA灯光控制台

### 可视化
- 节拍时间线显示（竖线高度=强度）
- 强拍/弱拍颜色区分（橙色/蓝色）
- 小节背景交替色
- 详细节拍数据表格

## 安装

```bash
pip install -r requirements.txt
```

## 使用方法

```bash
python main.py
```

1. 点击"加载WAV文件"选择音频文件
2. 调整分析参数（每小节拍数、灵敏度）
3. 点击"开始分析"
4. 查看节拍时间线和统计数据
5. 导出CSV或MA时间码

## 算法说明

### 节拍检测流程
1. **频谱通量计算** - 逐帧FFT，计算相邻帧频谱差异的半波整流
2. **自适应阈值峰值拾取** - 基于滑动窗口中位数的自适应阈值
3. **BPM估计** - 峰值间隔中位数法
4. **小节分组** - 基于BPM和每小节拍数的智能分组
5. **强度分类** - 基于小节内相对强度判断强拍/弱拍

### 参数说明
- **每小节拍数** - 2-8拍，默认4拍（4/4拍）
- **灵敏度** - 0.1-1.0，越高检测到的节拍越多

## 输出格式示例

### CSV格式
```csv
beat_number,timestamp,strength,bar_number,is_downbeat
1,0.0000,1.0000,1,1
2,0.5208,0.7500,1,0
3,1.0417,0.6800,1,0
4,1.5625,0.8200,1,0
```

### MA时间码格式
```
# MA Timecode - BPM: 120.0
# Time Signature: 4/4
# Format: TC | Bar.Beat | Strength | Type
00:00:00:00    1.1  100.0%  DOWN
00:00:00:15    1.2   75.0%      
00:00:01:01    1.3   68.0%      
00:00:01:17    1.4   82.0%      
```

## 注意事项

- 仅支持WAV格式音频文件
- 分析时间取决于音频长度
- 建议灵敏度从0.5开始调整
- 强拍识别基于相对强度，可能需要人工微调
