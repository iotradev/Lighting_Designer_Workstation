# BPM分析器 - 音乐节拍检测工具

## 简介
BPM分析器是灯光设计工作站的一部分，用于自动检测音频文件的BPM（每分钟节拍数），
帮助灯光设计师根据音乐节奏编排灯光效果。

## 功能特性
- **音频加载**: 支持WAV文件加载（MP3/FLAC/AAC需先转换为WAV）
- **BPM自动检测**: 基于能量的起始点检测算法
- **波形显示**: 使用QPainter绘制音频波形
- **BPM曲线**: 显示BPM随时间变化的曲线
- **统计信息**: 平均BPM、最小/最大BPM、标准差
- **CSV导出**: 导出分析结果到CSV文件
- **实时分析**: 定时滑动窗口分析模式
- **拖放支持**: 直接拖放音频文件到窗口

## 检测算法
1. 读取WAV音频采样数据（16/8/32位）
2. 多声道转单声道
3. 计算短时能量（20ms帧，10ms跳）
4. 计算能量差分并平滑
5. 自适应阈值峰值检测
6. 从起始点间隔计算BPM（中位数法）

## 安装依赖
```bash
pip install -r requirements.txt
```

## 使用方法
```bash
cd Tools/MusicAnalysis/BPMAnalyzer
python main.py
```

或从工作站主界面启动。

## 音频格式说明
当前仅支持WAV格式直接加载。对于MP3/FLAC/AAC等格式，
请使用FFmpeg等工具转换：
```bash
ffmpeg -i input.mp3 output.wav
```

## 界面布局
- **顶部**: 文件加载、参数设置、实时分析开关
- **左侧**: 波形显示区域（含起始点标记）
- **右侧**: BPM大数字显示 + 统计信息
- **底部**: BPM变化曲线 + 导出按钮
