# AudioSpectrum - 音频频谱分析工具

## 概述
基于FFT的实时音频频谱分析工具，提供频谱显示、瀑布图和频段能量监测。

## 功能
- **WAV音频加载**: 支持标准WAV格式文件
- **实时FFT频谱显示**: 滑动窗口频谱分析，支持1024/2048/4096 FFT大小
- **7频段能量监测**:
  - Sub-bass (20-60Hz)
  - Bass (60-250Hz)
  - Low-mid (250-500Hz)
  - Mid (500-2kHz)
  - High-mid (2k-4kHz)
  - High (4k-8kHz)
  - Ultra-high (8k-20kHz)
- **峰值频率检测**: 实时识别当前最强频率
- **频谱瀑布图**: 颜色映射的频率-时间显示
- **频段能量仪表**: 7个垂直柱状图实时显示各频段能量

## 使用方法
1. 点击"加载音频"选择WAV文件
2. 点击"播放"开始实时分析
3. 调整FFT大小选择器改变频率分辨率
4. 观察频谱、瀑布图和频段能量仪表

## 依赖
- PySide6
- numpy
