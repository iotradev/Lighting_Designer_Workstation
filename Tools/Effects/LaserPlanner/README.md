# 激光规划器 (LaserPlanner)

激光安全规划工具，用于规划舞台激光区域、计算安全距离并生成安全报告。

## 功能

- **激光区域定义**: 在舞台布局上绘制矩形/圆形激光区域
- **安全区域计算**: 基于 MPE（最大允许照射量）计算安全距离
- **观众排除区域**: 定义观众排除区域
- **光束路径可视化**: 使用 QPainter 绘制激光光束路径
- **区域重叠检测**: 检测区域重叠并显示警告
- **安全报告导出**: 导出 CSV 格式安全报告

## 使用方法

```bash
python main.py
```

## 依赖

- Python 3.8+
- PySide6
