# 像素映射器 (PixelMapper)

LED矩阵网格设计器，支持像素到DMX通道映射、颜色图案编辑和动画预览。

## 功能

- **LED矩阵网格设计** - 可配置4x4到64x64的网格大小
- **DMX通道映射** - 自动分配或手动设置DMX地址
- **颜色图案编辑** - 画笔/橡皮擦/填充工具绘制图案
- **内置图案** - 彩虹渐变、颜色波浪、棋盘格、螺旋
- **动画预览** - 基于图案生成动画帧并播放
- **JSON导出** - 导出灯具位置和DMX映射数据

## 使用方法

```bash
python main.py
```

## 文件结构

- `main.py` - 主窗口UI和交互逻辑
- `pixel_engine.py` - 像素数据模型、DMX映射、图案生成器
- `requirements.txt` - Python依赖
- `README.md` - 本文件
