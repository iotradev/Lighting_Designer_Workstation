# Cue设计器 (CueDesigner)

灯光演出Cue列表管理与预览工具。

## 功能

- **Cue管理**: 创建、编辑、删除Cue，设置编号、名称、淡入/淡出时间、延迟
- **Cue列表**: 可排序表格显示，支持上移/下移调整顺序
- **追逐模式**: 设置追逐速度，按顺序链接Cue
- **效果生成器**: 正弦波、随机闪烁、随机颜色效果，可选通道范围
- **实时预览**: 512通道DMX值网格显示
- **交叉渐变**: 在两个Cue间按淡入淡出时间进行动画过渡
- **导入/导出**: 保存/加载项目JSON，导出CSV

## 界面布局

- **左侧**: Cue列表表格 + 操作按钮
- **中部**: Cue编辑面板 + 通道值网格(16×32)
- **右侧**: 效果生成器面板
- **底部**: 预览控制(Go/Back/Stop) + 当前Cue信息 + DMX预览

## 运行

```bash
python main.py
```

## 依赖

- Python 3.9+
- PySide6
