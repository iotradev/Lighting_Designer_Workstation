# 演出管理器 (ShowManager)

**版本:** 1.0.0

## 功能

- 集中管理演出项目信息（名称、场地、灯光设计、日期等）
- 场景列表管理：添加、编辑、删除、排序场景
- 每个场景支持名称、描述、灯具预设
- Cue总览：汇总展示所有场景的Cue列表
- 时间线概览：可视化场景区块展示
- 导出节目单到CSV格式
- 保存/加载项目JSON文件

## 使用方法

```bash
python main.py
```

## 依赖

- Python 3.10+
- PySide6 >= 6.5.0

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建项目 |
| Ctrl+O | 打开项目 |
| Ctrl+S | 保存项目 |
| Ctrl+L | 日志窗口 |
| Ctrl+P | 项目管理器 |
