# 时间轴编辑器 (TimelineEditor)

**版本:** 1.0.0

## 功能

- 水平时间轴标尺，支持缩放和滚动
- 轨道系统：每条轨道对应一个灯具组或属性
- 关键帧编辑：在轨道上添加/删除关键帧点
- 三种插值模式：线性、阶跃、缓入缓出
- 播放头控制：播放、暂停、停止
- 导出时间线为Cue列表JSON
- 保存/加载时间线项目文件

## 使用方法

```bash
python main.py
```

## 操作说明

- 在轨道区域 **左键点击** 添加关键帧
- 在关键帧表中查看和管理所有关键帧
- 使用缩放滑块调整时间轴精度
- 播放时自动遍历关键帧生成效果

## 依赖

- Python 3.10+
- PySide6 >= 6.5.0
