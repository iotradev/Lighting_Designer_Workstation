# MIDI映射器 (MIDI Mapper)

## 概述
MIDI信号到灯光控制的映射工具，支持将MIDI控制器（键盘、推子、旋钮等）的输入信号映射到DMX通道、场景触发等灯光控制动作。

## 功能特性

### MIDI Learn模式
- 开启Learn模式后，操作MIDI控制器自动捕获输入信号
- 自动创建映射条目，无需手动填写MIDI参数
- 支持连续捕获多个映射

### 映射类型
| MIDI输入 | 说明 | 典型用途 |
|----------|------|----------|
| CC (Control Change) | 控制器变化 (0-127) | 推子、旋钮连续控制 |
| NoteOn | 按键按下 | 按钮触发场景/宏 |
| NoteOff | 按键释放 | 按钮释放动作 |
| PitchBend | 弯音轮 | 连续无级控制 |

### 输出动作
- **DMX通道**: 直接控制DMX通道值 (格式: `通道号/最大值`, 如 `1/255`)
- **场景触发**: 触发预设场景
- **宏命令**: 执行宏命令序列

### 配置管理
- 映射配置保存为JSON格式
- 支持多套配置文件切换
- 可导入/导出配置共享

## 使用方法

### 启动
```bash
cd D:/Lighting_Designer_Workstation/Tools/MIDI/MIDIMapper
python main.py
```

### 基本操作流程
1. 在顶部选择MIDI输入设备
2. 点击"MIDI Learn模式"开启
3. 操作MIDI控制器（推子/按钮/旋钮）
4. 系统自动捕获并创建映射
5. 在映射表中调整输出动作和参数
6. 保存配置文件

### 映射表编辑
- **添加映射**: 点击"添加映射"按钮手动添加
- **删除映射**: 选中行后点击"删除选中"
- **编辑参数**: 直接在表格中修改
- **启用/禁用**: 通过每行的复选框控制

### 测试模式
选中映射行，点击"测试映射"按钮，系统发送模拟MIDI消息验证映射是否正确触发。

## 依赖
- Python 3.10+
- PySide6 >= 6.5.0
- python-rtmidi >= 1.5.0 (可选，无硬件时使用stub模式)

## 配置文件格式 (JSON)
```json
{
  "version": "1.0",
  "mappings": [
    {
      "input_type": "CC",
      "input_channel": 0,
      "input_number": 1,
      "output_action": "DMX通道",
      "output_param": "1/255",
      "enabled": true
    }
  ]
}
```
