# MIDI Monitor - MIDI 信号监控工具

实时监控 MIDI 输入设备，显示并分析 MIDI 消息。

## 功能

- 实时监控 MIDI 输入设备
- 颜色编码消息类型（音符开启=绿色, 音符关闭=红色, 控制变化=橙色等）
- 消息日志与过滤
- 统计信息：消息计数、活动音符、CC 值
- 虚拟 MIDI 端口支持
- 演示模式（无需真实 MIDI 设备）

## 依赖

```
pip install -r requirements.txt
```

## 运行

```
python main.py
```

## 使用说明

1. 从设备下拉框选择 MIDI 输入设备
2. 点击「开始监听」
3. 实时查看消息表格和统计面板
4. 使用复选框过滤消息类型
