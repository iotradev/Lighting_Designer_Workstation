# AI灯光设计助手 (AILightingDesigner)

## 版本
1.0.0

## 简介
基于规则的灯光设计建议工具。根据场地类型、情绪描述和可用灯具，自动生成专业的灯光设计方案。

## 功能特性
- **场地类型选择**: 支持剧院、演唱会、会议室、宴会厅、户外音乐节、演播室等
- **情绪分析**: 从文本中提取情绪关键词，匹配最佳灯光方案
- **颜色面板建议**: 根据情绪自动生成主色、副色、强调色、环境色
- **CUE序列生成**: 根据场地类型和能量级别生成完整的CUE序列
- **灯位建议**: 根据场地类型推荐灯具安装位置和角度
- **导出功能**: 支持JSON和CSV格式导出

## 规则引擎逻辑
- 场地类型 → 默认灯位布局和推荐灯具
- 情绪关键词 → 颜色面板 (12种情绪预设)
- 能量级别 → CUE时间参数 (淡入/保持/淡出/交叉渐变)

## 使用方法
```bash
python main.py
```
