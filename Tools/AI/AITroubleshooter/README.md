# AI故障诊断 (AITroubleshooter)

## 版本
1.0.0

## 简介
基于规则的灯光系统故障诊断工具。通过选择症状，自动分析可能原因并提供逐步解决方案。内置20+常见问题数据库。

## 功能特性
- **症状分类**: DMX信号、网络、灯具、控制台、电源 五大类
- **多选诊断**: 支持同时选择多个症状进行综合诊断
- **严重程度**: 自动标记严重/中等/轻微三个等级
- **解决方案**: 每个问题提供详细的逐步排查方案
- **报告导出**: 生成完整的诊断报告JSON文件

## 症状数据库 (25条)
### DMX信号问题 (6条)
- 完全没有DMX信号
- DMX信号闪烁/不稳定
- 部分通道无响应
- 通道串扰/错误通道响应
- 灯具卡死不响应控制
- 控制延迟明显

### 网络问题 (5条)
- 无法连接到灯光网络
- 网络连接间歇性断开
- Art-Net/sACN响应缓慢
- IP地址冲突
- DHCP分配失败

### 灯具问题 (8条)
- 灯具完全不亮
- 灯具亮度明显降低
- 颜色显示不正确
- 摇头灯移动卡顿/异响
- 图案盘卡住
- 灯泡突然熄灭
- 风扇噪音异常
- 频闪无法控制

### 控制台问题 (4条)
- 控制台死机/无响应
- 推子不灵敏/跳值
- 显示屏异常
- 无法保存/加载演出文件

### 电源问题 (3条)
- 断路器跳闸
- 电路过载警告
- 接地回路噪音
