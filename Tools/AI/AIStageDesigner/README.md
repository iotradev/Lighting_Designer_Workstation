# AI舞美助手 (AIStageDesigner)

## 版本
1.0.0

## 简介
基于规则的舞台布局建议工具。根据演出类型和舞台尺寸，自动生成桁架布局和灯具位置建议，并提供可视化预览。

## 功能特性
- **演出类型**: 演唱会、话剧/戏剧、企业会议、舞蹈演出、时装秀
- **舞台尺寸**: 可配置宽度、深度、高度
- **桁架布局**: 根据舞台类型自动生成桁架结构建议
- **灯具放置**: 智能计算灯具在桁架上的分布位置
- **可视化预览**: 使用QPainter绘制舞台俯视图
- **详情表格**: 桁架和灯具的详细参数表
- **导出功能**: 导出为JSON格式

## 舞台类型说明
| 类型 | 特点 |
|------|------|
| 演唱会 | 主桁架+侧面+后方+T台，大量摇头灯和频闪 |
| 话剧/戏剧 | 前中后三区桁架+耳光，注重层次和氛围 |
| 企业会议 | 简洁的前后桁架，LED面板灯为主 |
| 舞蹈演出 | 三区+侧面桁架，均匀覆盖舞台 |
| 时装秀 | 主舞台+T台布局，追光灯重点 |

## 使用方法
```bash
python main.py
```
