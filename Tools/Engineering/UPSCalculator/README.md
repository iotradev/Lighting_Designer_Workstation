# UPS续航计算器 (UPSCalculator)

## 概述
UPS电池续航时间计算工具，支持多种电池配置和方案比较。

## 功能特性
- **续航计算**：Runtime = (Ah × V × η × DoD) / Load
- **电池配置**：支持串联（提高电压）和并联（提高容量）
- **多方案比较**：列表对比不同UPS配置的续航时间
- **详细信息**：显示有效容量、系统电压等参数

## 使用方法
1. 输入电池容量、电压、UPS效率和负载功率
2. 设置串联/并联电池数量
3. 点击"计算续航"查看结果
4. 点击"添加到比较列表"保存方案用于对比

## 依赖
- Python 3.9+
- PySide6 >= 6.5.0
