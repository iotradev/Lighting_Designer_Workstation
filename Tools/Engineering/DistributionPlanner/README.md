# 配电规划器 (DistributionPlanner)

## 概述
专业灯光系统配电规划工具，用于规划主供电到配电箱到各回路的配电方案，支持三相负载平衡。

## 功能特性
- **负载管理**：添加负载组（名称、功率、数量、指定相位）
- **三相平衡**：自动分配负载到三相，最小化不平衡度
- **配电图**：QPainter绘制功率流向树形图
- **过载警告**：自动检测总负载和单相过载
- **汇总统计**：实时显示各相功率和总计

## 使用方法
1. 输入负载名称、单组功率和数量
2. 选择相位分配方式（自动/手动指定）
3. 设置供电总容量
4. 点击"自动均衡"进行智能分配
5. 查看配电图和汇总结果

## 依赖
- Python 3.9+
- PySide6 >= 6.5.0
