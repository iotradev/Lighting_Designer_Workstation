# 线缆计算器 (CableCalculator)

## 概述
专业线缆计算工具，用于计算电压降、推荐线缆尺寸，并可视化线缆截面结构。

## 功能特性
- **电压降计算**：Vd = 2 × L × I × R / 1000
- **线缆尺寸推荐**：基于电流、距离和允许压降自动推荐标准线缆
- **载流量校验**：验证所选线缆是否满足载流需求
- **功率损耗计算**：计算线路功率损耗
- **可视化截面图**：QPainter绘制线缆截面结构
- **铜/铝材质选择**：支持铜线和铝线计算
- **参考数据**：内置常用线缆载流量参考表

## 使用方法
1. 输入电流、线缆长度、材质、电压和允许压降
2. 点击"计算"查看推荐线缆和各项结果
3. 右侧自动显示线缆截面示意图

## 依赖
- Python 3.9+
- PySide6 >= 6.5.0
