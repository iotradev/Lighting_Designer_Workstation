# 发电机容量计算器 (GeneratorCalculator)

## 概述
专业发电机容量选型工具，用于计算灯光系统所需的发电机容量和燃油消耗。

## 功能特性
- **容量计算**：根据负载功率、功率因数、启动系数计算所需kVA
- **启动系数**：考虑电机类负载的启动冲击电流
- **标准选型**：自动推荐最接近的标准发电机容量
- **燃油消耗**：计算额定和75%负载下的柴油消耗量
- **多场景比较**：保存和对比不同负载场景的发电机需求

## 使用方法
1. 输入负载总功率(kW)、功率因数、启动系数和冗余系数
2. 设置柴油机参数（燃油消耗率、柴油密度）
3. 点击"计算"查看推荐容量和油耗
4. 点击"保存场景"用于多场景对比

## 依赖
- Python 3.9+
- PySide6 >= 6.5.0
