# 功率计算器 (PowerCalculator)

## 概述
专业灯光系统功率计算工具，用于计算灯光设备的总功率需求、电流大小和安全裕量。

## 功能特性
- **灯具管理**：添加/删除灯具，设置名称、功率和数量
- **总功率计算**：自动汇总所有灯具总功率
- **电流计算**：支持单相和三相电流计算
  - 单相：I = P / (V × PF)
  - 三相：I = P / (√3 × V × PF)
- **功率因数校正**：支持自定义功率因数
- **安全裕量**：基于80%规则计算建议额定容量
- **结果汇总**：实时显示计算结果

## 使用方法
1. 在"添加灯具"区域输入灯具名称、功率(W)和数量
2. 点击"添加灯具"按钮
3. 设置电气参数（电压、功率因数、相数）
4. 点击"计算"查看结果

## 依赖
- Python 3.9+
- PySide6 >= 6.5.0
