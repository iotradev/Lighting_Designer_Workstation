# RDMTool - RDM管理工具

RDM (Remote Device Management) 设备发现与管理工具，灯光设计工作站组件。

## 功能

- **设备发现**: 模拟 RDM 设备发现流程，扫描 DMX 网络上的 RDM 设备
- **设备列表**: 以表格形式展示所有发现的设备（UID、标签、型号、固件、DMX地址、个性、通道占用）
- **参数读取**: 查看设备制造商、型号、工作模式、传感器等只读信息
- **参数设置**: 修改设备 DMX 起始地址、标签、识别模式
- **消息日志**: 记录所有 RDM GET/SET 消息交互

## 模拟设备

本工具使用内置模拟设备数据库，包含 8 台模拟设备（洗墙灯、追光灯、光束灯、频闪灯），无需真实硬件即可体验完整流程。

## 启动

```bash
cd Tools/DMX/RDMTool
python main.py
```

## 依赖

- Python 3.10+
- PySide6
