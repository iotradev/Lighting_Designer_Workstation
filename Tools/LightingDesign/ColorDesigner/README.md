# 色彩设计器 (ColorDesigner)

照明色彩设计与管理工具。

## 功能

- RGB 色彩混合器：3 个滑块（R/G/B 0-255）实时预览
- CMY 色彩混合器：3 个滑块（C/M/Y 0-100）
- 色温转换器：开尔文输入（2000-10000K）转 RGB 预览
- 色片库：常见 Lee/Rosco 色片颜色及色块
- 调色板管理器：保存/加载自定义调色板到 JSON
- 颜色预览：大色块 + 十六进制/RGB/CMY 值显示

## 使用

```bash
python main.py
```

## 依赖

- Python 3.9+
- PySide6>=6.5.0
